Yes.  Because Washington’s **Contractor Load** dataset is hosted on the state’s Data.WA platform (powered by Socrata), you can programmatically connect to it.  Socrata provides several options for consuming its data—CSV downloads, a RESTful **SODA** API and **OData** feeds—so most prospecting/CRM tools can import or sync the information.

### Why it’s connectable

The dataset is a table of licensed contractors that includes fields for the **business name**, **primary principal’s name**, address, city/state/zip and even a **phone number**.  The metadata shows that the “Primary Principal Name” field represents the primary owner or principal, and there is a “Phone Number” field for the business’s phone.  Because the dataset is on a Socrata-powered portal, it has built‑in API endpoints that can be used by other applications.

### Steps to integrate with your prospecting program

1. **Confirm import method.**  Check whether your prospecting program can import data from a **CSV** file or can make **HTTP API** requests.  Most CRMs allow CSV imports; some have connectors for Socrata/OData.
2. **Obtain the dataset endpoint.**  The Washington contractor dataset’s ID is `g526-rd4x`.  Use the CSV download URL for a one‑time import or the SODA/OData endpoint for ongoing integration.
3. **Fetch the data.**

   * For CSV import: download the file and upload it into your program.
   * For automated integration: write a script in your preferred language (e.g., Python using `requests` or the `sodapy` library) to call the API periodically and parse the JSON into your database.  Add query parameters to filter by status, license type, city, etc.
4. **Use an application token (optional but recommended).**  For frequent or high‑volume API calls, create a free account on Data.WA (or any Socrata portal) and request an **app token**.  Pass it as a `$$app_token` query parameter to avoid rate limits.
5. **Load into your prospecting program.**  Map the dataset fields (`businessname`, `primaryprincipalname`, `address1`, `city`, `state`, `zip`, `phonenumber`, etc.) to the corresponding fields in your program.  If your tool allows scheduling imports, configure it to refresh the data regularly.

By using these Socrata-provided endpoints, you can keep your prospecting database synchronized with the latest Washington contractor license information, including names and phone numbers.
